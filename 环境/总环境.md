# 总环境

本文记录项目当前使用的后端运行环境，便于后续迁移、压缩打包和复现。

## 运行环境

- 环境名：`edunova`
- Python 解释器：请在自己的机器上创建环境后，以实际 `python.exe` 路径为准。

## 导出方式

如果需要把这个环境导出给别人，优先导出 Conda 环境定义，再补一份 `pip` 依赖清单。

### 1. 导出 Conda 环境

```powershell
conda activate edunova
conda env export --no-builds > edunova-environment.yml
```

### 2. 导出 pip 依赖

```powershell
conda activate edunova
python -m pip freeze > edunova-requirements.txt
```

## 恢复方式

如果要在新机器上重建环境，可以先创建 Conda 环境，再安装依赖。

```powershell
conda env create -f edunova-environment.yml
conda activate edunova
python -m pip install -r edunova-requirements.txt
```

## 项目内约定

- 后端检查、测试、脚本运行，统一使用同一套 Python 环境
- 不使用项目内 `.venv`
- 不使用项目内 `.conda-env`
- 不依赖 `USER_SITE`

## 备注

如果导出后的环境文件里包含本机专属路径或无关缓存项，建议手动清理后再发给别人。
